# Pulsar: типы локальных экономик России по безналичным тратам

Решение Pulsar (Екатерина Алексанян) для онлайн-конкурса СберИндекса 2026, трек «Кластеризация»:
динамическая атрибутированная сеть муниципальных образований (МО), кластеризация, отслеживание изменений во времени и экономическая интерпретация типов.

- Лендинг: https://estnafinema0.github.io/sberindex-pulsar/
- Методологический отчёт: [docs/report.pdf](docs/report.pdf) (исходник LaTeX: [docs/report/report.tex](docs/report/report.tex); веб-версия того же текста: [docs/report.md](docs/report.md))
- Презентация: [docs/slides.pdf](docs/slides.pdf) ([исходник](docs/slides.md))
- Литература и эталонные методы: [docs/research/jury_literature.md](docs/research/jury_literature.md), [docs/research/benchmarks.md](docs/research/benchmarks.md)

## Главный результат

Модель выделяет шесть устойчивых типов локальных экономик: мегаполисы и столичные районы (16 % МО, траты 186 % от медианы страны), промышленные города и пригороды (20 %), малые города и райцентры (22 %), аграрные районы на трассах (16 %), сельская периферия (21 %, 82 % медианы), Север и ресурсные территории (6 %). Типы объясняют 61 % разброса зарплат и 48 % населения по Росстату, которых модель не видела. За два года 68 % МО не сменили тип; индекс Шоррокса по подтверждённым переходам равен 0,02 в месяц. Сильнее всего изменилась доля маркетплейсов: она удвоилась во всех типах, на Севере рост медленнее.

## Что сделано

1. Признаки (7 на МО-месяц): CLR долей шести категорий трат + лог-уровень трат относительно медианы страны; причинное сглаживание; z внутри месяца. → `src/pulsar/features.py`
2. Сеть из трёх слоёв, слитых через SNF: поведение (взаимный kNN с локальным ядром), со-движение (корреляции приростов с усадкой Ледуа–Вольфа) и география (гравитация по дорогам). Граф месяца t использует только данные ≤ t. → `src/pulsar/graphs.py`
3. Методы на одних и тех же X_t и A_t: k-means, Ward, Spectral, Leiden, temporal Leiden (Mucha 2010), KEFRiN (Shalileh & Mirkin 2022, реализация по формулам) и его сбалансированный вариант, который стал итоговым методом (K = 6). → `src/pulsar/methods.py`
4. ICVI: SW, CH, S_Dbw, AVI, AVU, MQ (+ ANUI, DBI, CH/N); свои реализации, сверены с библиотекой Pattern (1e-9); z-оценки против перестановок меток и configuration model; парный бутстрэп с ДИ; рейтинги Борда и пороговое правило Алескерова. → `src/pulsar/icvi.py`, `evaluate.py`, `compare.py`
5. Динамика без утечки будущего: подтверждённые переходы (≥3 мес.), индекс Шоррокса, события Greene, бутстрэп-уверенность типа, out-of-time проверка 2023 → 2024. → `src/pulsar/dynamics.py`
6. Интерпретация: профили по Миркину, дерево правил и внешняя проверка на данных, которых не было в кластеризации (Росстат: зарплаты, занятость, население; тип МО; доступность рынков). → `src/pulsar/interpret.py`
7. Лендинг: карта (Альберс) с ползунком месяцев и слоем неопределённости, паспорта типов и МО, аллювиальная диаграмма, таблицы качества. → `site/`

## Быстрый старт

```bash
python3.12 -m venv .venv && . .venv/bin/activate
make env        # зависимости (requirements.txt, фиксированные версии)
make all        # данные (SHA-256) → признаки → графы → кластеризация → сравнение → динамика → интерпретация → данные лендинга
make test       # юнит-тесты (ICVI сверены с Pattern при PATTERN_DIR=путь/к/Pattern)
```

Docker: `docker build -t pulsar . && docker run --rm -v $PWD/data:/app/data -v $PWD/outputs:/app/outputs pulsar make all`.

Лендинг локально: `python -m http.server 8765 -d site` → http://localhost:8765. PDF отчёта и слайдов: `make report` (отчёт собирается из `docs/report/report.tex` через [tectonic](https://tectonic-typesetting.github.io), слайды из `docs/slides.md` через Chrome/Chromium).

Гиперпараметры лежат в `configs/*.yaml`, у каждого есть комментарий, зачем он нужен. Seed везде 42. Время прогона указано в отчёте, приложение В.
